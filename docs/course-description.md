# Course description — Bayesian Techniques in Macroeconomics

Bayesian Techniques in Macroeconomics is a graduate course that trains students to move from a structural macroeconomic model to its formal estimation on real data. The objective is not to survey estimation techniques in the abstract, but to carry a single modelling thread — a small rational-expectations economy, then a full production (RBC) economy — through every stage of the empirical pipeline, so that each econometric object can be traced back to an explicit economic assumption. Starting from a non-linear expectational system of the form E_t[f_Θ(x_{t+1}, x_t, x_{t-1}, ε_t)] = 0, the course shows how first-order (perturbation) approximation around the steady state delivers a linear reduced form x̂_t = F x̂_{t-1} + Gε_t, and how a selection matrix linking a subset of model variables to observed series, y_t = H x̂_t + v_t, turns this reduced form into a state-space representation with an explicit transition and measurement equation. Building on this representation, the course introduces the Kalman filter as the recursive prediction-and-update algorithm that produces one-step-ahead forecast errors and their covariance, and shows how these Gaussian innovations combine into the sample log-likelihood of the model given the data. Maximum likelihood estimation is treated as the first, purely classical way of using this likelihood — numerically minimizing its negative to obtain point estimates of the structural parameters — while also surfacing its practical limits: weak or local identification, stochastic singularity, and the sensitivity of the likelihood surface to filter and data choices. The course then reframes estimation in Bayesian terms: prior distributions (Normal, Beta, Gamma, Inverse Gamma) encode disciplined, economically motivated information about structural parameters before any data are seen; Bayes' rule combines this prior with the likelihood into a posterior kernel; and, because the posterior has no closed form for a DSGE model, Markov Chain Monte Carlo methods — specifically the random-walk Metropolis-Hastings algorithm run from the posterior mode — are used to characterize the posterior distribution, with acceptance rates, chain mixing and convergence diagnostics treated as integral, non-optional parts of estimation rather than afterthoughts. Throughout, MATLAB and Dynare are used not as black boxes but as an explicit computational implementation of each analytical object covered in class: students write and inspect the state-space matrices, the Kalman recursions and the likelihood by hand in MATLAB before delegating the same computations, augmented with priors and Metropolis-Hastings sampling, to Dynare's `estimation()` command, so that every reported coefficient, standard error or posterior credible interval can be connected back to a specific equation of the underlying macroeconomic model.
