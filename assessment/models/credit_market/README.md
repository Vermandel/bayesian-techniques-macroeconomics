# Credit Market Model

Student-facing toy model for the credit-market assessment track.

## Files

- `statement.pdf`
- `model.mod`

## Goal

Study an entrepreneurial credit market model with borrowing frictions and use it as the basis for the assessment exercise.

## What to Check

- balance sheet identities;
- collateral constraints;
- steady state;
- shock processes;
- simulation and estimation readiness.

## Student Use

1. Read the statement.
2. Inspect the Dynare file.
3. Run the model.
4. Adapt the code to the assigned assignment workflow.

No correction file is published here.
