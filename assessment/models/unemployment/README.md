# Unemployment Model

Student-facing toy model for the unemployment assessment track.

## Files

- `statement.pdf`
- `model.mod`

## Goal

Study a labor-market model with unemployment, work through the Dynare template, and use it as the basis for the assessment exercise.

## What to Check

- equation timing;
- calibration values;
- steady state consistency;
- shock processes;
- observables used in the estimation or simulation step.

## Student Use

1. Read the statement.
2. Open the Dynare file.
3. Run the model and inspect the IRFs.
4. Adapt the template to the assigned data and estimation task.

No solution file is included here.
