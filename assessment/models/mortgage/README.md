# Mortgage Model

Student-facing toy model for the mortgage assessment track.

## Files

- `statement.pdf`
- `model.mod`

## Goal

Study a collateral and housing model with borrowing constraints, then use it as the basis for the assessment exercise.

## What to Check

- borrowing constraint;
- housing stock dynamics;
- Euler equations;
- calibration and steady state;
- simulation outputs.

## Student Use

1. Read the statement.
2. Inspect the Dynare file.
3. Run the baseline model.
4. Complete the estimation or calibration task described in the statement.

The teacher correction remains private.
