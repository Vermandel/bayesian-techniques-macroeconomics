# Open Economy Model

Student-facing toy model for the open-economy assessment track.

## Files

- `statement.pdf`
- `model.mod`

## Goal

Work through a two-country open-economy model, understand the relative price and external balance channels, and prepare the model for estimation or simulation.

## What to Check

- home/foreign symmetry;
- net foreign asset accumulation;
- real exchange rate dynamics;
- observables and calibration;
- Dynare consistency.

## Student Use

1. Read the statement.
2. Inspect the model equations.
3. Run the baseline simulation.
4. Adapt the model to the assignment instructions.

No private correction is stored here.
