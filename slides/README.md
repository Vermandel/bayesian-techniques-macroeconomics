# Slide decks

The four oral decks use Gauthier Vermandel's established Beamer visual system.
Each deck is shorter and more visual than its corresponding handout: it
introduces the session objective and references, gives a plan, then alternates
intuition, essential equations, diagrams, workflow and takeaways.

This public repository distributes the compiled PDFs together with their LaTeX
sources and the course-local Sorbonne reference theme assets in
`slides/template/assets/`.
