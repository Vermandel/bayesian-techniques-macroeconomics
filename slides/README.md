# Slide decks

The four oral decks use a copied, unmodified version of Gauthier Vermandel's
Sorbonne Beamer system (`mystyle_diapos2.tex`, Frankfurt/miniframes theme and
the Ewen companion assets). Source reference:
`Dropbox/Teaching/SU_RisquesClimatiques/Session0/assets/`.

The copy in `template/assets/` is intentionally course-local so that BTM can
compile independently without changing the historical source. Each deck is
shorter and more visual than its corresponding handout: it introduces the
session objective and references, gives a plan, then alternates intuition,
essential equations, diagrams, workflow and takeaways.
