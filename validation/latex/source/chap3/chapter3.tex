\section{Introduction}

\noindent There are different way to parametrize a macroeconomic
models.\ These parametrization methods can be listed as follows:

\begin{itemize}
\item Calibration;

\item Matching Moments;

\item Estimation:

\begin{itemize}
\item Maximum Likelihood;

\item Bayesian Estimation;
\end{itemize}
\end{itemize}
The calibration strategy usually relies on a \textsf{qualitative approach}.
The model that is calibrated is not meant to provide a full description of
some economic data, instead, it aims at describing simple economic
mechanisms. This is usually addressed through the lens of simple toy models.
The problem with the calibration strategy is that it is difficult to choose the
right values for the parameters. The difficulty of the calibration strategy
can be summarized in a critique by \cite{pindyck2017use} of economic models of
climate change as follows: \textquotedblleft\textit{Because the modeler has so
much freedom in choosing functional forms, parameter values, and other inputs, the model can be used to obtain
almost any result one desires (...)}\textquotedblright.

In contrast, the estimation strategy relies on a positive approach: it is
aimed at replicating either some specific features of the data (aka
'\textsf{weak information method}'), or all the information offered by the
data (aka '\textsf{full information method}'). This dichotomy is referred to by
econometricians as the weak versus full-information methods. Note the first
prototype of a DSGE model by \cite{kydland1982time} was based on the weak
information method in the sense that the model was calibrated to match some
moments of the data. Econometricians needed more effort in research to align the
model closely with the data. \cite{taylor1990solving} and \cite{fair1990full} provide
some examples of estimated DSGE models using the maximum
likelihood method. This handout provides an introduction to the estimation of linear
models using full information methods.

\section{Filters}

Filters are statistical methods which allows to extract relevant information
from data. For a macro-econometrician, filtering consists of using the model
to extract the sequence of shocks from macroeconomic time series.\ Note that
for a given same sample, there are an infinite number of sequences of shocks
and models that can replicate that sample.\ So the extracted sequence of
shocks of one model provide one - among many possible - representation of the
data. The key aspect of the estimation is therefore to pick the set of
parameters that maximizes the joint density that is the most favored by the data.

\subsection{The Kalman filter}

The Kalman filter was initially developed for engeneering control problem
(e.g. Nasa spatial program).\ In this section, we follow Hamilton's notation
and will set up the Kalman filter on general time series model. First, the
Kalman filter is linear, so this filter can only be employed for the
estimation of linear models. Since most of DSGE\ models are simulated using a
linear approximation, the Kalman has become very popular for the estimation of DSGE\ models.

First, note that when we try to put the model to the data, there are observed
and unobserved variables. Think about a RBC\ model with physical capital,
consumption, productivity and investment, an econometrician is able to observe
consumption and investment because these are available as macroeconomic time
series, while physical capital and productivity are not directly
observable.\footnote{For physical capital, we are not sure exactly at which
rate physical capital depreciates. Similarly, the measure of productivity is
also subject to endless controversies (think about the Solow's residual).}

The set of unobserved state is given by:%
\begin{equation}
x_{t}=Fx_{t-1}+G\varepsilon_{t},\text{ with }\varepsilon_{t}\sim
\mathcal{N}(0,Q) \label{eq: unobserved variables}%
\end{equation}
where the covariance matrix of errors is given by $E(v_{t},v_{t}^{\prime})=Q$,
$v_{t}\sim N(0,Q)$ is a vector of stochastic disturbances, $F$ is a full rank
matrix.\ Note that this equation transition is a transition equation as it
describes how a set of unobservable state variations evolves over time. Note
that the system in \autoref{eq: unobserved variables} is actually the policy
rule of our model. Regarding the set of observable variables, the equation
reads as:
\begin{equation}
y_{t}=Hx_{t}+v_{t},\text{ with }v_{t}\sim\mathcal{N}(0,R)
\label{eq: observed variables}%
\end{equation}
where $w_{t}$\ is a vector of stochastic disturbances which are interpreted as
measurement errors with $w_{t}\sim N(0,P)$, $M$\ is a matrix that describes
how observable variables are related to unobserved ones. This equation will be
described in the model as \textsf{measurement equations}.%
\begin{equation}
y_{t}=HFx_{t-1}+HG\omega_{t}+v_{t}%
\end{equation}


Note that we don't allow for the stochastic disturbances $\omega_{t}$\ and
$v_{t}$\ to be correlated (but we could relax this assumption).

Back to the Kalman filter, the latter allows an econometrician to retrieve the
values of $x_{t}$, $v_{t}$\ and $w_{t}$ that replicate $y_{t}$. We assume for
now that $H$, $F$, $G$, $R$ and $Q$ are known and time unvarying (without a
loss of generality).\ \ We provide data Y and matrices H F\ and G, and the
filter provides the vectors or errors and their (un)conditional moments.

The prediction errors $y_{t}-E_{t-1}\{y_{t}\}$\ are given by:%
\begin{equation}
S_{t}=y_{t}-E_{t-1}\{y_{t}\}=y_{t}-HE_{t-1}\{x_{t}\}, \label{eq KF1}%
\end{equation}
while the prediction errors variance $\Omega_{t}=E\left(  S_{t}S_{t}^{\prime
}\right)  $ is given by:
\begin{equation}
\Omega_{t}=HE_{t-1}E_{t-1}\{\Sigma_{t}\}H^{\prime}+R. \label{eq KF2}%
\end{equation}


The 'best' prediction in the Kalman filter is defined as the optimal mean
squared error (MSE) estimator:
\[
\min E\left(  y_{t}-E_{t-1}\{y_{t}\}\right)  \left(  y_{t}-E_{t-1}%
\{y_{t}\}\right)  ^{\prime},
\]
where $K_{t}$\ represents a closed-form expression of the estimator, it plays
a key role in determining how the predictions of the model adjust to surprises
(i.e. unexpected shocks $\omega_{t}$).\ The formula of $K_{t}$ reads as
follows:%
\begin{equation}
K_{t}=E_{t-1}\{\Sigma_{t}\}H^{\prime}\Omega_{t}^{-1} \label{eq KF3}%
\end{equation}


Next, we can compute the Kalman filter's recusion. We are interested in
computing an estimate of $x_{t}$ given 'surprises' in $y_{t}$ (surprises are
the errors of predictions).\ Update of the state mean $x_{t}$ and
variance-covariance $\Sigma_{t}$ based on the new surprise are given by:
\begin{align}
x_{t}  &  =E_{t-1}\{x_{t}\}+K_{t}S_{t}\label{eq KF4}\\
\Sigma_{t}  &  =E_{t-1}\{\Sigma_{t}\}-K_{t}HE_{t-1}\{\Sigma_{t}\}
\label{eq KF5}%
\end{align}


Finally, we can forecast state mean and variance-covariance, based on the
current state mean and covariance $x_{t}$ and $\Sigma_{t}$, as follows:%
\begin{align}
E_{t}\{x_{t+1}\}  &  =Fx_{t}\label{eq KF6}\\
E_{t}\{\Sigma_{t+1}\}  &  =F\{\Sigma_{t}\}F^{\prime}+GQG^{\prime}
\label{eq KF7}%
\end{align}


Note that if you need to run the Kalman filter, you need to pre-define $H$,
$G$, $F$, $R$, $C$, and $Q$, provide the data $y_{t}$, and the filter (based
on equations \autoref{eq KF1}-\autoref{eq KF7}) provides $S_{t}$, $\Omega_{t}%
$, $x_{t}$, $\Sigma_{t}$, $E_{t}\{x_{t+1}\}$\ and $E_{t}\{\Sigma_{t+1}\}$. The
only last remaining thing that must defined are the initial conditions,
$E_{0}\{x_{1}\}$ and $E_{0}\{\Sigma_{1}\}$, in the recursive equations
\ref{eq KF4}-\ref{eq KF5}.

\subsection{The Inversion Filter}

As an alternative to the Kalman, we can use the inversion filter of
\cite{kollmann2013estimating} that can serve the sequence of errors of any
model (either linear or non-linear).

Consider a selection matrix denoted $H$ such that the set of observable is
given by $y_{t}=Hx_{t}$. Note that there as many rows as endogenous variables
$n_{x}$ and as many column as observable variables $n_{y}$, this matrix is of
all zeros except for row/column observables variables that must include a
dummy.\ Mapping the model $y_{t}$\ to the data $Y_{t}$ implifies that:%
\begin{align*}
Y_{t}  &  =y_{t}\\
&  =Hx_{t}\\
&  =HFx_{t-1}+HG\varepsilon_{t}%
\end{align*}
We thus solve the equation in $\varepsilon_{t}$\ such that the closed-form
expression for the contemporaneous realization of shocks:%
\begin{equation}
\varepsilon_{t}=\left(  HG\right)  ^{-1}\left(  Y_{t}-HFx_{t-1}\right)
\label{eq 4}%
\end{equation}


Note that the error of forecasts, denoted $Y_{t}-HFx_{t-1}$, is the economic
surprise that is rescaled to the model's shock size through the product with
the term $\left(  HG\right)  ^{-1}$. Therefore using this equation, we can
extract the sequence of errors recursively.

To summarize, the inversion filters work by inverting the policy rule to infer
the sequence of shock and next compute the current prediction for states
variables as follows:%
\[
\left\{
\begin{array}
[c]{c}%
\varepsilon_{t}=\left(  HG\right)  ^{-1}\left(  Y_{t}-HFx_{t-1}\right) \\
x_{t}=Fx_{t-1}+G\varepsilon_{t}%
\end{array}
\right.  ,
\]
for a sample of size $t=1:T$. The usual assumption for initial conditions is
to set $x_{0}=\bar{x}$\ where $\bar{x}$ is the deterministic steady state.

\subsection{The particle filter}

Particle filters allow the inference of dynamic macroeconomics models, the
latter can be non-linear and/or with non-normal errors. \ We refer to
\cite{fernandez2007estimating} for a full description of the application to DSGE\ models.

\subsection{A quick discussion}

What is the difference between the inversion and the Kalman filter? The Kalman
filter is the best linear estimator, so it picks the 'best' sequence of
shocks\ that minimizes the mean squared errors.\ But if there are as many
shocks as observable variables (that is mostly the case for estimated DSGE)
then there is only one possible sequence of shock so there is no 'best"
prediction.\ However, if there are more shocks than observable variables, then
the Kalman is useful to find the 'best' sequence of errors.\ Note in
\autoref{eq 4}, we can use the inversion filter only if matrix $\Lambda G$\ is
square and invertible.\ Put differently, the inversion filter only works if
the number of observable variables is the same as the sequence of errors to be
estimated. Given this restriction on the inversion filter, 99.9\% yet use the
Kalman filter to evaluate the sequence of error of the model.\ For non-linear
models, the particle filter is the best solution to smooth the shocks, however
its application is computatinally intensive, so the big drawback is the time
for the filter to get the sequence of errors.

Now that we are able to get the sequence of errors that replicate some
observable variable, the next step is to pick the best set of parameters that
replicates the data.\ The maximum likelihood is the criterion for this.

\section{Maximum likelihood}

In statistics, maximum likelihood estimation (MLE) is a method of estimating
the parameters of a probability distribution by maximizing a likelihood
function, so that under the assumed statistical model the observed data is
most probable. From a statistical standpoint, a given set of observations are
a random sample from an unknown population. The goal of maximum likelihood
estimation is to make inferences about the population that is most likely to
have generated the sample.

\subsection{An illustration with a simple gaussian case}

For time series models with gaussian errors and continuous data, let us assume
the most simplistic forecasting model of the form:%
\[
x_{t}=\varepsilon_{t}\text{ with }\varepsilon_{t}\sim\mathcal{N}(\mu
,\sigma^{2}).
\]


The forecast error of this model reads as follows:%
\[
S_{t}=x_{t}-E_{t-1}\{x_{t}\}=\varepsilon_{t}.
\]
Conditional likelihood associated with a realization of $x_{t}$ can be
assessed as the likelihood assigned by its probability density function. Note
that if shocks $\varepsilon_{t}$ are gaussian, then the error of predictions
are gaussian, $S_{t}\sim\mathcal{N}(\mu,\sigma^{2})$. By assuming normality,
we simply assume the shape of our data distribution to conform to the Gaussian
bell curve. As we know from statistics, the specific shape and location of our
Gaussian distribution come from $\sigma$ and $\mu$ respectively. These two
parameters are what define our curve, as we can see when we look at the
Probability Density Function (PDF) of the gaussian distribution:\footnote{Most
of this subsection is strongly inspired by
https://towardsdatascience.com/maximum-likelihood-estimation-explained-normal-distribution-6207b322e47f.}%
\begin{align*}
P\left(  \varepsilon_{t}\right)   &  =\frac{1}{\sqrt{2\pi V\left(
\varepsilon_{t}\right)  }}\exp\left(  -\frac{\left(  \varepsilon_{t}-E\left(
\varepsilon_{t}\right)  \right)  ^{2}}{2V\left(  \varepsilon_{t}\right)
}\right) \\
&  =\frac{1}{\sqrt{2\pi\sigma^{2}}}\exp\left(  -\frac{\left(  \varepsilon
_{t}-\mu\right)  ^{2}}{2\sigma^{2}}\right)
\end{align*}
To be technically correct, we can say we are looking for a curve that
maximizes the probability of our data given a set of curve parameters. If we
want to match a simple gaussian distribution, $\theta=\{\mu,\sigma\}$. We can
set up the problem as a conditional probability problem, of which the goal is
to maximize the probability of observing our data given $\theta$. Therefore,
for a dataset with only one observation (it does not make sense for a
continuous probability distribution but it's only for illustrative purpose),
we obtain:
\begin{equation}
P\left(  \varepsilon_{t}|\theta\right)  =\frac{1}{\sigma\sqrt{2\pi}}%
\exp\left(  -\frac{\left(  \varepsilon_{t}-\mu\right)  ^{2}}{2\sigma^{2}%
}\right)  ,\text{ with }\theta=\{\mu,\sigma\}.
\end{equation}


For a dataset of size $T$, mathematically we can express it as follows:%
\begin{equation}
P\left(  x_{1},x_{2},...,x_{T}|\theta\right)
\end{equation}
Because we are dealing with a continuous probability distribution, however,
the above notation is technically incorrect, since the probability of
observing any set of continuous variables is equal to zero. Conceptually, this
makes sense because we can come up with an infinite number of possible
variables in the continuous domain, and dividing any given observation by
infinity will always lead to a zero probability, regardless of what the
observation is.

We need to think in terms of probability density rather than probability.
Without going into the technicalities of the difference between the two, we
will just state that probability density in the continuous domain is analogous
to probability in the discrete domain. Therefore, probability density can be
used in this maximization problem. To correct our notation, we will say:%
\[
\underset{\text{probability}}{\underbrace{P\left(  x_{1},x_{2},...,x_{T}%
|\theta\right)  }}\rightarrow\underset{\text{density}}{\underbrace{f\left(
x_{1},x_{2},...,x_{n}|\theta\right)  }}%
\]
We want to \textsf{maximize the probability density of observing our data as a
function of }$\theta$. In other words, we want to find $\mu$ and $\sigma$
values such that this probability density term is as high as it can possibly
be. We are used to $x$ being the independent variable by convention. But in
this case, we are actually treating $\theta$ as the independent variable, and
we can consider $x_{1},x_{2},...,x_{T}$ to be a constant, since this is our
observed data, which cannot change.

From probability theory, we know that the probability of multiple independent
events all happening is termed \textsf{joint probability}. We can treat each
data point observation as one single event; therefore we can treat the
observation of our exact dataset as a series of events, and we can apply joint
probability density as follows:%

\begin{align}
f\left(  x_{1},x_{2},...,x_{T}|\theta\right)   &  =f\left(  x_{1}%
|\theta\right)  \cdot f\left(  x_{2}|\theta\right)  \cdot...\cdot f\left(
x_{T}|\theta\right) \label{eq lk1}\\
&  =\Pi_{t}^{T}f\left(  x_{t}|\theta\right) \nonumber
\end{align}


To illustrate how the log-likelihood can serve to find the best model,
consider the first MATLAB\ box. We sample some random draws from gaussian
distribution $\varepsilon_{t}\sim N(0.1,1)$, which is referred to as the true
data generating process.\ Using the sequence of $\varepsilon_{t}$ that we
interpret as our sample, we compare alternative distributions drawn
respectively from $\theta^{\prime}=\{2,1\}$ and $\theta^{\prime\prime
}=\{0.1,0.6\}$ .%

%TCIMACRO{\TeXButton{MATLABbox}{\MATLABboxPDF{LK}}}%

\MATLABboxPDF{LK}%
%EndExpansion


As reported in the left panel, the true gaussian curve in blue ($\varepsilon
_{t}$) is strongly different from the predictions of yellow ($\theta
^{\prime\prime}$) and red ($\theta^{\prime}$) distributions. These theoretical
curves can also be compared with the data $\varepsilon_{t}$ in the right
panel. Therefore, the goal of the likelihood function as described in
\autoref{eq lk1} is to assess which of the curve on the left is the closest to
data on the right. By calculating the value of the likelihood, we see that
$L\left(  Y,\theta\right)  $%

$>$

$L\left(  Y,\theta\right)  $ and $L\left(  Y,\theta^{\prime\prime}\right)  $.

Remember, the goal is to maximize this probability density term by finding the
optimal $\theta$.\ So we are looking for the value of $\theta$\ that maximizes
the probality density, which is also referred to as the maximimum likelihood
estimator. It can be expressed as follows:%
\[
\hat{\theta}_{MLE}=\arg\max_{\theta}\Pi_{t}^{T}f\left(  x_{t}|\theta\right)
\]
This problem can be easily solved using optimization routines of MATLAB.
However, it's rather typical to apply two tricks to faciliate the manipulation
and the resolution of the maximum likelihood problem:

\begin{enumerate}
\item Apply logs to linearize (it's easier to code sums than products, it's
also easier to calculate gradients on sums than products);

\item Minimize the minus of the likelihood.
\end{enumerate}

First, we linearize the previous expression:%
\begin{align*}
\log(\Pi_{t}^{T}f\left(  x_{t}|\theta\right)  )  &  =\log(f\left(
x_{1}|\theta\right)  )+\log(f\left(  x_{2}|\theta\right)  )...\\
&  =%
%TCIMACRO{\dsum \limits_{t=1}^{T}}%
%BeginExpansion
{\displaystyle\sum\limits_{t=1}^{T}}
%EndExpansion
\log(f\left(  x_{t}|\theta\right)  )\\
&  =%
%TCIMACRO{\dsum \limits_{t=1}^{T}}%
%BeginExpansion
{\displaystyle\sum\limits_{t=1}^{T}}
%EndExpansion
\left[  -\frac{1}{2}\log(2\pi\sigma^{2})-\frac{\left(  \varepsilon_{t}%
-\mu\right)  ^{2}}{2\sigma^{2}}\right] \\
&  =-\frac{T}{2}\log(2\pi\sigma^{2})-\frac{1}{2\sigma^{2}}%
%TCIMACRO{\dsum \limits_{t=1}^{T}}%
%BeginExpansion
{\displaystyle\sum\limits_{t=1}^{T}}
%EndExpansion
\left(  \varepsilon_{t}-\mu\right)  ^{2}%
\end{align*}


Finally, in most softwares, it's easier to minimize than maximize, so the
maximum likelihood estimator reads as follows:%
\begin{equation}
\hat{\theta}_{MLE}=\arg\min_{\{\theta\}}\left\{  -\log(f\left(  x_{1}%
,x_{2},...,x_{T}|\theta\right)  )\right\}
\end{equation}

\subsection{Maximum likelihood for DSGE\ models}

The previous subsection describes the maximum likelihood estimator with one
exogenous variables. However most of macroeconomic models typically includes
more than one observable variables. For a $n$ number of observed variables,
the errors of predictions of the estimated model follows $S_{t}\sim
\mathcal{N}(\mu_{t},\Omega_{t})$ with $\mu_{t}$\ the mean and $\Sigma_{t}%
$\ the covariance of errors of predictions, the general expression of the
likelihood function reads as follows:%
\begin{equation}
\log L=-\frac{nT}{2}\log(2\pi)-\frac{1}{2}\sum_{1}^{T}\log\left(  |\Omega
_{t}|\right)  -\frac{1}{2}\sum_{1}^{T}\left(  y_{t}-E_{t-1}\{y_{t}\}\right)
^{\prime}\Omega_{t}^{-1}\left(  y_{t}-E_{t-1}\{y_{t}\}\right)  .
\end{equation}


\textsf{Kalman filter.}\ For an estimation that uses the Kalman filter, the
likelihood can be computed by picking the endogenous distribution of errors of
predictions in \autoref{eq KF1} and \autoref{eq KF2}:%
\begin{equation}
\log L=-\frac{nT}{2}\log(2\pi)-\frac{1}{2}\sum_{1}^{T}\log\left(  |\Omega
_{t}|\right)  -\frac{1}{2}\sum_{1}^{T}S_{t}{}^{\prime}\Omega_{t}^{-1}S_{t}
\label{eq LLK DSGE KF}%
\end{equation}


\textsf{Inversion filter.}\ For an estimation based on the inversion filter to
extract the sequence of errors, we have the exact value of the likelihood
function (as there is no time-varying uncertainty in the prediction errors
stemming from the recursion). The closed-form expression of the errors of
predictions are given in \autoref{eq 4} with $\varepsilon_{t}\sim
\mathcal{N}(0,Q)$, therefore the likelihood reads as follows:%
\begin{equation}
\log L=-\frac{nT}{2}\log(2\pi)-\frac{1}{2}\sum_{1}^{T}\log\left(  |Q|\right)
-\frac{1}{2}\sum_{1}^{T}\varepsilon_{t}^{\prime}Q^{-1}\varepsilon_{t}.
\label{eq LLK DSGE IF}%
\end{equation}

at least one shock to estimate a model with one observable.\ Since we only
have one shock in the model, our setup only admits one observable variable.
This variable will be consumption because it's one of the easy to find

\section{\ Maximum Likelihood Estimations with Dynare}

\subsection{Data transformation}

A key problem when performing fit exercises with DSGE\ models is to map a
stationary model with non stationary-data.\ Macroeconomic time series, like
GDP, are better characterized as non-stationary processes that have no
tendency to return to a deterministic path as underlined by
\cite{nelson1982trends} and thus requires data transformation to get them stationnary.

There are two main components which makes the GDP steadily grow (as underlined
by the \cite{solow1956contribution} model):

\begin{enumerate}
\item Technological changes.

\item The population.
\end{enumerate}

First, the first way to remove a non stationnary component in the GDP is to
divide it by the working population.\ Indeed, the growth of the population
makes the GDP steadily increase at least at the same rate as the
population.\ It is also possible to remove technological changes by rewritting
the model in terms of effective labour units as in Solow's model (this step is
explained in the following subsection).

First consider real GDP. Many macroeconomic series are available from
\textsc{DB}$\cdot$\textsc{nomics}. For reproducibility, use the supplied
\texttt{download\_data.py} script: it queries the versioned API endpoint,
stores the unmodified JSON response, and records the exact series code. Never
rely on an undocumented manual download or a machine-specific MATLAB helper.

\begin{enumerate}
\item[6.] Recall that in the model, each random variable $\hat{x}_{t}$ is
expressed in terms of detrended percentage deviations from the steady state:%
\begin{equation}
\hat{x}_{t}\simeq\log\left(  \frac{X_{t}}{\bar{X}_{0}\gamma^{t}}\right)
\end{equation}
where $X_{t}$\ \ is the non-linear expression of $\hat{x}_{t}$, $\bar{X}%
$\ \ is the empirical mean (or the steady state) of $X_{t}$\ and $\gamma^{t}%
$\ is the trend component. We transform our sample in the same vein, we first
express in terms of log deviations from the trend $\hat{X}_{t}\simeq
\log\left(  X_{t}/\gamma^{t}\right)  $, we store the result in a variable
called \textsf{ln\_gap}\ in Matlab. Then, we remove the steady state,\textit{
i.e.} the mean of the sample such that $\hat{x}_{t}=\hat{x}_{t}-\mu\left(
\hat{X}_{t}\right)  $ where $\mu(\cdot)$ is the empirical mean, and add the
resulting values to the chart.

To have our in data consistent with the model, (a) we need to apply logs to
our data, (b) remove the trend $\gamma^{t}$, (c) remove the mean/steady state:

\item[a] First , we apply the log. Variable \textsf{ln\_y}\ is the log of output:
\end{enumerate}

Consider now adding another time serie in the model: consumption.\ It is thus
possible to get directly from dbnomics.

To avoid stochastic singularity issue, you must have the same number of shocks
(or more) than observables.\ Estimation is ok as long as estimated parameters
(including shock variances) are identified (i.e. different from 0\ and not
estimated on their lower/upper bound). To estimate consumption, we need to add
one more shock to the model. To increase demand shock effects, we also include
investment $I_{t}$ in the GDP.

Let's consider a public spending shock in the GDP:%
\[
Y_{t}=C_{t}+I_{t}+G_{t}%
\]
Public spending $G_{t}$ is financed by a tax $T_{jt}$ charged to all
households populating our economy, assuming a balanced government budget over
the cycles:%
\[
G_{t}=%
%TCIMACRO{\dint \nolimits_{0}^{1}}%
%BeginExpansion
{\displaystyle\int\nolimits_{0}^{1}}
%EndExpansion
T_{jt}\text{d}j
\]
This tax affects the budget constraint of the household:%
\[
C_{jt}+K_{jt}+T_{jt}=A_{t}K_{t-1}^{\alpha}+\left(  1-\delta\right)  K_{jt-1}%
\]
Spending are exogenously determined as a constant fraction of the GDP
($\bar{G}=g^{y}\bar{Y}$):%
\[
G_{t}=\bar{G}\varepsilon_{t}^{G}\text{ with }\log\left(  \varepsilon_{t}%
^{G}\right)  =\rho_{G}\log\left(  \varepsilon_{t-1}^{G}\right)  +\eta_{t}^{G}%
\]
our model is now summarized by: $\ $%
\begin{align}
\hat{c}_{t}  &  =-\beta\alpha\bar{k}^{\alpha-1}\left(  \mathbb{E}_{t}\hat
{a}_{t+1}-\left(  1-\alpha\right)  \hat{k}_{t}\right)  +\beta\left[
\alpha\bar{k}^{\alpha-1}+\left(  1-\delta\right)  \right]  \mathbb{E}_{t}%
\hat{c}_{t+1}\\
\hat{y}_{t}  &  =\hat{a}_{t}+\alpha\hat{k}_{t-1}\\
\bar{y}\hat{y}_{t}  &  =\bar{c}\hat{c}_{t}+\bar{\imath}\hat{\imath}_{t}%
+g^{y}\bar{y}\hat{g}_{t}\\
\delta\hat{\imath}_{t}  &  =\hat{k}_{t}-\left(  1-\delta\right)  \hat{k}%
_{t-1}\\
\hat{a}_{t}  &  =\rho_{A}\hat{a}_{t-1}+\eta_{t}^{A}\\
\hat{g}_{t}  &  =\rho_{G}\hat{g}_{t-1}+\eta_{t}^{G}%
\end{align}
with $g^{y}=0.2$, \textit{i.e.} spending shocks accounts for 20\%\ of output
variations. The steady state thus reads as follows:%
\begin{align*}
\bar{k}  &  =\left(  \left[  \frac{1}{\beta}-\left(  1-\delta\right)  \right]
\frac{1}{\alpha}\right)  ^{1/\left(  \alpha-1\right)  }\\
\bar{\imath}  &  =\delta\bar{k}\\
\bar{y}  &  =\bar{k}^{\alpha}\\
\bar{c}  &  =\left(  1-g^{y}\right)  \bar{y}-\bar{\imath}%
\end{align*}
Our economy is characterized \ by a set of six variables $\left\{  \hat{c}%
_{t},\hat{k}_{t},\hat{y}_{t},\hat{\imath}_{t},\hat{a}_{t},\hat{g}_{t}\right\}
$.

\begin{enumerate}
\item Code the new model.

\item Estimate the new model with consumption and output, estimate the
variance of the spending shock as well as its AR(1) term.

\item Analyse the variance decomposition.\ Which shock is driving/explaining
the business cycles for the US\ economy?

\item Is the slope of the trend different for consumption and the GDP? (In the
next exercise, we will develop a method to estimate one single trend for both
consumption and GDP).

\item Let's try to develop and compare an alternative shock which could
explain the US\ business cycles.\ Include the following preference shock to
the model:%
\[
\max_{C_{jt},K_{jt}}\mathbb{E}_{t}\sum_{\tau=0}^{+\infty}\beta^{\tau
}\varepsilon_{t+\tau}^{C}\log\left(  C_{jt+\tau}\right)
\]


\begin{enumerate}
\item How the Euler equation is affected by this shock?

\item Estimate this new model with its AR(1) terms defined as:
\[
\log\left(  \varepsilon_{t}^{C}\right)  =\rho_{C}\log\left(  \varepsilon
_{t-1}^{C}\right)  +\eta_{t}^{C}%
\]


\item Which model is better given the data? (compare the model with government
spending shock, preference shock and both shocks).
\end{enumerate}
\end{enumerate}

\begin{myexercise}{Estimating deep parameters}
\addcontentsline{toc}{section}{Exercise \thetcbcounter}%

Consider in this exercise the simple model without consumption/investment.\ It
is possible to estimate parameters such as $\beta$, $\alpha$ and $\delta$.
However, these parameters affect the steady state of the model. Indeed, recall
that:%
\begin{align*}
\bar{k}  &  =\left(  \left[  \frac{1}{\beta}-\left(  1-\delta\right)  \right]
\frac{1}{\alpha}\right)  ^{1/\left(  \alpha-1\right)  }\\
\bar{c}  &  =\bar{k}^{\alpha}+\delta\bar{k}\\
\bar{y}  &  =\bar{k}^{\alpha}%
\end{align*}
Each time $\beta$, $\alpha$ and $\delta$ are changed to maximize the
log-likelihood function, the steady state should be updated accordingly. It is
thus easy in Dynare to update the steady of the model. In\textsf{
model(linear);}\ 's block, add:%

%TCIMACRO{\TeXButton{BeginCode}{\vspace{3ex}
%\begin{mybox}{code}}}%
%BeginExpansion
\vspace{3ex}
\begin{mybox}{code}%
%EndExpansion


\textsf{\#Kss = ((1/beta-(1-delta))/alpha)\symbol{94}(1/(alpha-1));}

\textsf{\#Css = Kss\symbol{94}alpha - delta*Kss;}%

%TCIMACRO{\TeXButton{EndCode}{\end{mybox}
%\vspace{3ex}}}%
%BeginExpansion
\end{mybox}
\vspace{3ex}%
%EndExpansion


At the begining of your Dynare file, you shall remove $Kss$\ and $Css$\ from
the parameter's block \textsf{parameters ...;} to make dynare update these
parameters each iteration.

Any parameter in model's block preceded by the sign "\textsf{\#}" is updated
by Dynare each iteration of the optimization algorithm employed in the fit exercise.

\begin{enumerate}
\item Estimate the value $\delta$ and look at the t-stat.\ Is this parameter
statistically significant?\ From this result, try to explain why $\delta$ is
not well identified.

\item Do you find a similar result for $\beta$, $\alpha$?\ Given the data, is
your fit better with or without these parameters?

\item \cite{smets2007shocks} obtain a well idenfitied estimation of $\alpha$
and $\beta$ for the US economy.\ Do you find such a result with that simple RBC\ model?
\end{enumerate}
